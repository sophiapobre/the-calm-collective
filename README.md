# Assignment 2

by Sophia Pobre

This project is a data-driven e-commerce website called RandomShop, which carries items from 3 random categories: Electronics, Bags, and Shoes.

### Pages 

- **Home:** Directly links to the Categories, Search, and Cart pages.
- **Categories:** A list of all products under each category. Each product's image and title can be clicked to view that product's details page.
- **Product Details:** Displays the product's name, image, price, description, and an "Add to Cart" button that allows the user to add the product to their cart. Upon adding an item to the cart, the cart counter at the top right of the page will increment. NOTE: The cart data does not persist across page refreshes, as this was not required in the assignment specifications.
- **Search:** Allows the user to search for products (exact matches only). If matching product(s) are found, the product's name, price, and image are displayed. Otherwise, the user is informed that no matching products were found.
- **Cart:** Displays a list of products that the user has added to their cart, showing each product's name, image, price, quantity, and total, as well as the overall cart total. The user can also clear their cart from this page.

### Extra Feature

If the user has added item(s) to their cart, the Cart page will contain a "Clear Cart" button, which removes all items from the user's cart and resets the cart counter at the top right of the page to 0. The "Clear Cart" button then disappears, and the user is told that their shopping cart is empty.
